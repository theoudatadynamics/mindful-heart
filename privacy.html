Privacy, in plain words.

This describes the Mindful Heart Mac beta and this website. The app sends feedback only when you choose to send a reviewed report.

Free web reader

The optional reader serves 21 reviewed classic excerpts. Favourites and your chosen appearance are stored in this browser on this device. They are not uploaded or synced. Your browser may clear this storage. Where supported, a service worker saves only the reader pages, icons and public quote catalog for offline use. It never caches Mac application downloads or clipboard data.

The reader has no account, advertising, tracking scripts or automatic analytics sender. It does not access the Mac app’s current quote, library or reminders. Sharing a quote link is an explicit action; links contain only a public quote identifier. GitHub hosts the files and processes connection information as explained below.

Your clipboard stays on your Mac

Clipboard history starts disabled. If you enable it, the app records future clipboard changes into a local library. The history keeps the latest 100 ordinary items; saving or pinning lets you retain useful items. Text, images and file references are not uploaded by Mindful Heart.

The app skips copies marked private, temporary or automatically generated by their source app. Not every application uses those markers, so this is not a guarantee that every password or sensitive item will be detected. Pause history before copying anything you do not want stored.

Optional usage totals

Usage collection also starts disabled. If you turn it on in Settings → Privacy & beta, the app records counts for this fixed list of actions:

  • App launches.
  • Opening Quotes, Wellness, Clipboard or Settings.
  • Requesting the next quote or copying a quote.
  • Opening the clipboard picker or copying a stored clipboard item.

A usage export contains those totals, a report-format version and the app version. It does not contain clipboard contents, quote text, search terms, screenshots, file paths, other application names, email addresses, device identifiers or a sequence of individual action timestamps.

Turning collection off clears the local totals. You can also clear the totals while collection is enabled. No data is collected retrospectively.

Usage data is never sent automatically. You can export these totals or explicitly choose to attach them to a feedback report.

Feedback is your choice

Starting in version 1.66, Settings → Privacy & beta lets you review a report before choosing Send feedback. Theoú Data Dynamics receives your message, feedback type, app version and build, a random receipt ID and the time we received it. Usage totals are included only when you select them. Cloudflare processes the submission and ordinary connection details, including your IP address, to deliver it and limit abuse. The feedback inbox does not store your IP address.

We use the reports to investigate problems and improve Mindful Heart. Support has access to the private inbox. Reports are removed after about 90 days, and recovery backups may retain deleted reports for up to seven more days. For questions or deletion requests, send your receipt to jeevan@theoudatadynamics.com.

Please leave clipboard contents, passwords and private work information out of your message. Save a copy creates a local file. GitHub feedback is public and opens a separate form.

Permissions and connected services

Apple Reminders access is optional. Mindful Heart reads reminders to show the list and optional nudges. In version 1.69 and later, choosing Save reminder writes the new item to your chosen Apple Reminders list. A dated item includes an alert at its due time. Apple Reminders handles the alert and syncing through your account. Mindful Heart does not include reminder text in feedback or usage totals unless you choose to type it in your feedback. Optional menu-bar auto-fit uses Accessibility access, which is a broad macOS permission. If enabled, a separate signed menu-bar helper runs outside App Sandbox, giving that process broader OS access. The main app and clipboard remain sandboxed. The helper code requests only menu-bar geometry, roles and identifiers; it does not request window text, clipboard contents, screenshots or keystrokes. Layout data is not saved or sent. Manual quote width works without this permission. Publisher reading links, sharing controls and other external links open services you choose to use. Those services apply their own privacy practices.

Optional nearby quote sync

Nearby sync starts only when you choose Find devices. Both devices must confirm a matching code before saved quote text is shared. Sharing the current Mac quote needs a separate opt-in. A confirmed live connection can remain open after leaving the pairing screen; Stop sync disconnects it, and moving the companion app to the background ends its connection. Clipboard contents, reading history, reminders and account details are not included. There is no hosted sync server or automatic analytics upload.

The Mac app stays sandboxed but has incoming and outgoing network entitlements, which permit broader networking than a local-only session. The implemented quote transport uses an encrypted nearby session. macOS Local Network approval remains your choice. Native companion builds are still experimental; nearby sync does not guarantee locked-screen updates.

Call-aware speech

Call-aware speech checks whether an audio input is active and skips or stops quote speech while input is in use. It does not record audio, inspect call contents or send input-activity data. It can also suppress speech during recording or dictation and may not detect a receive-only call.

Update checks

Update checks and automatic installation start off. If you check for updates, the app contacts GitHub, which receives your IP address and standard connection details. Clipboard contents, searches and usage totals are not included. Earlier sandboxed betas can update through this channel.

Wellness timing and speech

Reminder identifiers, schedules and next-due dates are saved locally so restarting does not postpone reminders. This timing checkpoint contains no reminder text. Quote speech selects a matching installed Apple voice on this Mac; the app does not send the text to a cloud speech service.

Quote rotation and session state

The current quote, rotation deadline and hashes identifying quotes already shown are saved in local app preferences. This keeps the quote cycle and timing across restarts. Private custom quote text may be part of this local state; it is not attached to update checks or usage reports. Sleep, display, session and advisory screen-lock events are used to stop or suppress speech. No new permission, session recording or polling is added.

Local storage and deletion

Your settings and library are stored separately from the application. Existing-library migration from earlier builds is still being tested. Back up saved items before updating an existing installation. Deleting the application alone does not necessarily delete its local library. Use the app's library controls to manage stored items; do not share a library backup as a usage report.

Public download counts

The website reads public aggregate archive counters from the GitHub API. It sends no visitor ID, cookie, email, clipboard contents or app usage report. GitHub receives ordinary connection information from this request and from file downloads. Separate file links identify the website, GitHub and in-app update download channels; they do not identify people or prove installation. A saved count is shown with its timestamp if live counts are unavailable. These totals are also used by the owner’s local dashboard.

This website preview

The page loads its styles and scripts locally. It has no analytics scripts, advertising, third-party fonts, cookies or tracking identifiers. The color-theme switch changes the current page only.

The interactive preview uses sample contents and does not read your clipboard. Pressing “Copy quote” writes only the displayed sample quote to your clipboard.

This website is hosted on GitHub Pages. GitHub logs and stores visitor IP addresses for security purposes. See GitHub’s hosting information and privacy statement. We have not added a website analytics service.
