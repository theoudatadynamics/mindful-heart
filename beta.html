Get started

  1. Download and double-click the ZIP to extract Mindful Heart.app.
  2. Move the app to your Applications folder, then open it.
  3. Complete the welcome steps. Choose your quote rhythm and where quotes appear.
  4. Leave clipboard history, Reminders access and usage collection off unless you want them.

If Apple cannot verify the app

You may see “Mindful Heart Not Opened” and a message that Apple could not verify the app is free of malware. This beta has not been notarized by Apple. If you trust this download and choose to continue:

  1. Click Done in the warning.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the message about Mindful Heart and click Open Anyway.
  4. Authenticate with your Mac password or Touch ID if asked.
  5. Click Open in the confirmation dialog.

macOS saves an exception for this app, so you can normally open it afterwards by double-clicking it. These are Apple’s documented steps.

Do not disable Gatekeeper or run Terminal commands to remove security protections. If the warning says the app contains malware, will damage your computer, or is damaged, stop and report the exact message instead. If Open Anyway is unavailable on a managed Mac, contact its administrator.

This universal download includes Apple Silicon and Intel builds and targets macOS 13.5 or later. Intel and older macOS runtime testing is still pending. Check your chip and macOS version under Apple menu → About This Mac.

How downloads are counted

The website button starts a direct ZIP download; it does not open a GitHub page. Website, GitHub and in-app update links use separate, byte-identical signed archives. The total adds each archive counter once. These are download events, not unique people or confirmed installations.

Channel attribution follows the link used, even if that link is shared. Counts include repeat downloads and verification tests. Existing GitHub counts mix direct downloads and earlier updater downloads, so they remain a separate historical bucket. Earlier files served directly by this website, old direct links, and copies shared elsewhere cannot be counted here.

Help us test the everyday details

  1. A thought that stays visible. Check the menu bar quote, read a long quote to its end, search the library and save a favourite.
  2. A timely pause. Set one wellness nudge. Check that it appears briefly and the regular menu bar quote continues afterwards.
  3. A useful snippet. Create harmless sample text, edit it, rename it, pin it and place it in a category. Open the picker with Control + Option + V, copy it, and paste with Command-V.
  4. A smooth return. Quit and reopen the app. Check that your favourite and test snippet remain. Try sleep and wake and light and dark modes.

Optional usage feedback

Update consent does not enable usage collection. If you choose to share feature-use counts, open Settings → Privacy & beta and turn on Collect optional usage totals on this Mac. After using the app, open See exactly what is recorded, review the counts, then choose Export usage totals…. Share that JSON file with your beta contact only if you want to. Do not send a clipboard-library backup.

Your data stays yours

The download contains no developer clipboard library or preferences. Clipboard capture starts off. Optional usage totals remain local; there is no automatic analytics receiver. Read the privacy details.
