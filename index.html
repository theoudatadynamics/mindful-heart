Before you begin

A few things to know.

Which Macs can run this beta?

This universal package includes Apple Silicon and Intel builds. Intel runtime testing is still pending. It targets macOS 13.5 and later, but compatibility with every supported macOS release has not yet been verified. Tell us your macOS version if something does not work.

Are Bible verses available offline?

The library has 20 topics with 20 references each. Telugu and Hindi IRV texts are bundled with their attribution notices. English ESV and NASB 2020 currently offer references and publisher reading links; their full texts are not bundled.

How do I share feedback?

In the app, choose Help → Send Feedback. Write your feedback, choose Review and send, then select Send feedback. Keep the receipt if you need support. Read the feedback privacy details.

What if macOS blocks the app?

This beta is not notarized by Apple. If you trust the download and choose to proceed, click Done, open System Settings → Privacy & Security, select Open Anyway beside Mindful Heart, authenticate if asked, then confirm Open. Follow the first-launch steps. Do not disable system security. Stop if macOS reports malware or a damaged app.

How do updates work?

Sparkle update support is included. Automatic checks and installation start off. Use Check for Updates in the app menu; earlier sandboxed betas can update to 1.67 through this channel. People upgrading an older installation should wait for the migration instructions. Read the beta guide.
